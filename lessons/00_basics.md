# 0강. 프로그래밍 기초 용어와 이론

코드를 한 줄도 몰라도 괜찮아요. 이 문서는 1강을 시작하기 전에 읽는 **용어 사전 + 기초 이론**입니다.
어려운 말은 전부 스카이림에 빗대어 설명합니다.

---

## 1. 컴퓨터와 프로그램

### 컴퓨터는 무엇을 할 수 있나?
컴퓨터는 사실 아주 단순한 일만 합니다.

1. **기억하기** — 값을 저장해 둔다
2. **계산하기** — 더하기, 빼기, 비교하기
3. **순서대로 따라 하기** — 적힌 명령을 위에서 아래로 하나씩 실행

대신 이걸 1초에 수십억 번 합니다. 그래서 스카이림 같은 게임도 돌아가는 거예요.

### 프로그램 (Program)
컴퓨터에게 시키는 **명령들의 목록**. 요리 레시피와 같아요.
스카이림(`SkyrimSE.exe`), 모드 매니저, 크롬 브라우저 모두 프로그램입니다.

### 프로그래밍 (Programming) / 코딩 (Coding)
프로그램을 **만드는 일**. 컴퓨터에게 시킬 명령을 글로 적는 일입니다.

### 코드 (Code) / 소스 코드 (Source code)
프로그래밍 언어로 적어 둔 **명령문 글**. 우리가 `.py` 파일 안에 쓰는 글자들이 코드예요.

### 프로그래밍 언어 (Programming language)
컴퓨터에게 명령할 때 쓰는 **약속된 문법의 언어**. 사람 말은 애매해서 컴퓨터가 못 알아듣기 때문에 규칙이 엄격한 언어를 씁니다.

| 언어 | 어디에 쓰이나 |
|---|---|
| **Python (파이썬)** | 이 강의에서 쓰는 언어. 문법이 쉬워서 입문용·도구 만들기에 인기 |
| Papyrus (파피루스) | 스카이림 **게임 안** 모드 스크립트 (퀘스트, 마법 효과 등) |
| C++ | 스카이림 게임 엔진 자체, SKSE 플러그인 |
| C# | 유니티 게임, 일부 모딩 툴 |

### 실행 (Run / Execute)
적어 둔 코드를 컴퓨터가 **실제로 따라 하게 하는 것**.
`python3 lessons/01_mod_info.py` 라고 치면 파이썬이 그 파일을 위에서부터 한 줄씩 실행합니다.

### 인터프리터 (Interpreter)
코드를 한 줄씩 읽어서 실행해 주는 **통역사 프로그램**. `python3` 가 바로 파이썬 인터프리터예요.

### 터미널 (Terminal) / 명령 프롬프트 / 콘솔
마우스 대신 **글자로 명령을 입력하는 창**.
스카이림에서 `~` 키를 눌러 여는 콘솔 창과 같은 개념이에요. (`tgm` 대신 `python3 ...` 을 치는 것)
- Windows: 시작 → "cmd" 또는 "PowerShell" 또는 "터미널"
- 이 강의의 모든 실행 명령은 터미널에 입력합니다.

## 2. 데이터(값)에 관한 용어

### 값 (Value) / 데이터 (Data)
프로그램이 다루는 **정보 한 조각**. `"CoolArmor"`, `30`, `1.2`, `True` 같은 것.

### 변수 (Variable)
값을 담아 두는 **이름 붙은 상자**.
```python
gold = 100        # "gold" 라는 상자에 100 을 넣는다
gold = gold - 30  # 상점에서 30 골드를 쓰면 → 상자 안 값이 70 으로 바뀐다
```
- `=` 는 수학의 "같다"가 아니라 **"오른쪽 값을 왼쪽 상자에 넣어라"** 라는 뜻이에요.
- 스카이림 캐릭터의 체력, 골드, 레벨이 모두 게임 속 변수입니다.

### 자료형 (Data type) / 타입
값의 **종류**. 종류에 따라 할 수 있는 일이 달라요.

| 자료형 | 파이썬 이름 | 예 | 스카이림 비유 |
|---|---|---|---|
| 정수 | `int` | `30`, `-5` | 골드, 레벨 |
| 실수 | `float` | `1.2`, `3.14` | 무게 `2.5` |
| 문자열 | `str` | `"Whiterun"` | 아이템 이름, 대사 |
| 불리언 | `bool` | `True`, `False` | 퀘스트 완료했나? 예/아니오 |
| 리스트 | `list` | `["검", "방패"]` | 인벤토리 (순서 있는 목록) |
| 딕셔너리 | `dict` | `{"이름": "리디아"}` | 캐릭터 정보창 (항목 → 값) |

### 문자열 (String)
**글자들의 줄**. 반드시 따옴표 `"..."` 로 감싸요.
`"100"` 은 글자 1·0·0 이고, `100` 은 숫자예요. 둘은 다릅니다!

### 형 변환 (Type conversion)
값의 종류를 바꾸는 것. `int("100")` → 글자 `"100"` 을 숫자 `100` 으로.

## 3. 명령에 관한 용어

### 문법 (Syntax)
언어의 **규칙**. 괄호를 닫지 않거나 따옴표를 빼먹으면 "문법 오류(SyntaxError)"가 나요.

### 연산자 (Operator)
계산이나 비교를 하는 **기호**.
- 계산: `+` `-` `*`(곱하기) `/`(나누기) `%`(나머지)
- 비교: `==`(같다) `!=`(다르다) `>` `<` `>=` `<=` → 결과는 `True` 또는 `False`
- 논리: `and`(그리고) `or`(또는) `not`(아니다)

### 조건문 (Conditional) — `if`
**"만약 ~라면 이걸 해라"**.
```python
if gold >= 1000:
    print("집을 살 수 있어요!")
else:
    print("골드가 부족해요.")
```
NPC가 "평판이 높으면 할인해 준다"는 것도 게임 속 조건문이에요.

### 반복문 (Loop) — `for`, `while`
**같은 일을 여러 번 반복**.
```python
for item in ["검", "방패", "포션"]:
    print(item, "을(를) 팔았다")
```
인벤토리의 모든 아이템을 하나씩 확인하는 것처럼요.

### 함수 (Function)
여러 명령을 묶어서 **이름을 붙인 것**. 한 번 만들어 두면 이름만 불러서 계속 쓸 수 있어요.
스카이림의 **"샤우트"** 와 비슷해요. `Fus Ro Dah` 라고 외치면 정해진 동작이 한 번에 일어나죠.
```python
def heal(hp):          # 함수 만들기(정의): 이름은 heal, 받는 값은 hp
    return hp + 50     # 결과를 돌려준다(return)

new_hp = heal(30)      # 함수 부르기(호출) → new_hp 는 80
```
- **매개변수 (Parameter)**: 함수가 받는 값 (`hp`)
- **인자 (Argument)**: 함수를 부를 때 실제로 넣는 값 (`30`)
- **반환값 (Return value)**: 함수가 돌려주는 결과 (`80`)
- **호출 (Call)**: 함수를 실행시키는 것 — `이름()`

### 메서드 (Method)
특정 값에 딸린 함수. 값 뒤에 `.` 을 찍고 씁니다.
`"CoolArmor.ESP".lower()` → `"coolarmor.esp"` (문자열의 "소문자로 바꾸기" 기능)

### 들여쓰기 (Indentation)
줄 앞의 **공백(스페이스 4칸)**. 파이썬에서는 들여쓰기로 "이 줄이 어디에 속하는지"를 표시해요.
```python
if gold >= 1000:
    print("집 구매")    # ← 들여썼으니 if 에 속함
print("끝")            # ← 들여쓰지 않았으니 if 와 상관없이 항상 실행
```

### 주석 (Comment)
`#` 뒤에 쓰는 **메모**. 컴퓨터는 무시하고 사람만 읽어요.

## 4. 에러와 디버깅

### 에러 (Error) / 예외 (Exception)
프로그램이 실행 중 문제를 만나 멈추는 것. **절대 겁먹을 필요 없어요.** 프로그래머는 하루에도 수십 번 봅니다.

에러 메시지는 **맨 아래 줄부터** 읽으세요.
```
  File "lessons/01_mod_info.py", line 12       ← 12번째 줄에서
    print(mod_nme)
NameError: name 'mod_nme' is not defined        ← mod_nme 라는 이름이 없다 (오타!)
```

| 자주 보는 에러 | 뜻 |
|---|---|
| `SyntaxError` | 문법이 틀림 (괄호·따옴표·콜론 빠짐) |
| `IndentationError` | 들여쓰기가 맞지 않음 |
| `NameError` | 없는 이름을 씀 (대부분 오타) |
| `TypeError` | 종류가 안 맞는 값끼리 계산 (`"10" + 5`) |
| `ValueError` | 값이 이상함 (`int("abc")`) |
| `FileNotFoundError` | 파일이 그 경로에 없음 |

### 버그 (Bug) / 디버깅 (Debugging)
- **버그**: 프로그램이 의도와 다르게 동작하는 것. 스카이림의 "하늘을 나는 마차"도 버그예요.
- **디버깅**: 버그의 원인을 찾아 고치는 일.

## 5. 파일과 컴퓨터 내부

### 파일 (File) / 경로 (Path)
- **파일**: 저장 장치에 저장된 데이터 덩어리. `plugins.txt`, `CoolArmor.esp`
- **경로**: 파일의 **주소**. `C:\Games\Skyrim\Data\CoolArmor.esp`
- **폴더 (디렉터리)**: 파일을 담는 상자
- **확장자 (Extension)**: 파일 이름 끝의 `.esp`, `.txt`, `.py` — 파일 종류를 알려 줌

### 텍스트 파일 vs 바이너리 파일
- **텍스트 파일**: 메모장으로 열면 읽을 수 있는 파일 (`plugins.txt`, `.py`)
- **바이너리 파일**: 메모장으로 열면 깨진 글자만 보이는 파일 (`.esp`, `.exe`, 이미지)
  → 정해진 **형식(포맷)** 을 알고 있어야 해석할 수 있어요. 8강에서 `.esp` 를 해석해 봅니다.

### 비트 (Bit)와 바이트 (Byte)
- **비트**: 컴퓨터가 저장하는 가장 작은 단위. `0` 또는 `1` 하나. (전기가 꺼짐/켜짐)
- **바이트**: 비트 8개 묶음. 0~255 까지의 숫자 하나를 저장할 수 있어요.
- 1KB ≈ 1,000바이트, 1MB ≈ 100만 바이트, 1GB ≈ 10억 바이트

### 16진수 (Hexadecimal)
숫자를 0~9, A~F 의 **16개 기호**로 쓰는 방법. (A=10, B=11, … F=15)
- 10진수 `10` = 16진수 `0A`,  `255` = `FF`
- 바이트 하나(0~255)를 딱 두 글자(`00`~`FF`)로 쓸 수 있어서 컴퓨터 분야에서 많이 써요.
- **스카이림 콘솔의 FormID** 가 바로 16진수예요! `player.additem 0000000F 100` 의 `0000000F` = 골드.
  FormID 앞 두 자리(`00`, `01`, …)는 **로드 오더 번호**라서, 로드 오더가 중요한 거예요.

## 6. 도구와 협업

### 라이브러리 (Library) / 모듈 (Module) / `import`
다른 사람이 미리 만들어 둔 **코드 묶음**. 가져다 쓰면 직접 만들 필요가 없어요.
스카이림 모드가 SKSE나 SkyUI 같은 "필수 선행 모드"를 쓰는 것과 같아요.
```python
import random          # 무작위 숫자 라이브러리 가져오기
```

### Git / GitHub / 커밋 / PR
- **Git**: 코드의 **세이브 파일 시스템**. 언제든 예전 상태로 되돌릴 수 있어요.
- **커밋 (Commit)**: 세이브 한 번. "여기까지 작업했다"고 기록하는 것.
- **GitHub**: Git 세이브를 올려 두는 인터넷 저장소 (코드판 넥서스 모드 사이트).
- **브랜치 (Branch)**: 본편과 따로 진행하는 **평행 세이브 슬롯**.
- **PR (Pull Request)**: "내 브랜치의 변경을 본편에 합쳐 주세요"라는 요청.

## 7. 스카이림 모딩 용어 (이 강의에서 쓰는 것)

| 용어 | 뜻 |
|---|---|
| 플러그인 | `.esp` / `.esm` / `.esl` 파일. 게임 데이터를 추가·수정하는 파일 |
| `.esm` (마스터) | 다른 모드가 기대는 기반 파일. `Skyrim.esm` 이 게임 본체 데이터 |
| `.esp` | 일반 플러그인. 대부분의 모드 |
| `.esl` (라이트) | 254개 제한에 포함되지 않는 가벼운 플러그인 |
| 마스터 (의존성) | 어떤 플러그인이 동작하려면 반드시 있어야 하는 다른 플러그인 |
| 로드 오더 | 게임이 플러그인을 불러오는 순서. 뒤에 오는 것이 앞의 것을 덮어씀 |
| `plugins.txt` | 켜 둔 플러그인과 순서가 적힌 텍스트 파일 |
| Data 폴더 | 게임 설치 폴더 안의, 모드 파일이 들어가는 곳 |
| CTD | Crash To Desktop. 게임이 튕겨서 바탕화면으로 나가는 것 |
