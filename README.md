## VFX 테스트베드 빠른 시작

Unity 메뉴에서 **`Tools > VFX Testbed > Build Test Stage`** 를 실행하면
격자 바닥·스케일 기준물·배경값 전환·라이팅 프리셋·블룸 토글이 갖춰진 테스트 씬이 생성됩니다.
외부 에셋은 필요하지 않습니다.
