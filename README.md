# game — 파이썬으로 배우는 프로그래밍 기초

프로그래밍을 처음 배우는 사람을 위한 단계별 강의입니다.
마지막 강의에서 직접 **숫자 맞히기 게임**을 만들어 봅니다.

## 준비하기

1. [python.org](https://www.python.org/downloads/)에서 Python 3를 설치합니다.
2. 터미널(명령 프롬프트)에서 설치를 확인합니다.
   ```
   python3 --version
   ```
   (Windows에서는 `python --version`)

## 강의 순서

| 강 | 파일 | 배우는 내용 |
|---|---|---|
| 1 | `lessons/01_print_and_variables.py` | 출력, 변수, 사칙연산, f-string |
| 2 | `lessons/02_input_and_types.py` | 입력 받기, 자료형 변환 |
| 3 | `lessons/03_conditions.py` | 비교/논리 연산, if / elif / else |
| 4 | `lessons/04_loops.py` | for, while, range, break |
| 5 | `lessons/05_lists.py` | 리스트 만들기·꺼내기·수정하기 |
| 6 | `lessons/06_functions.py` | 함수 정의, 매개변수, return |
| 7 | `lessons/07_game_number_guess.py` | 🎮 종합 실습: 숫자 맞히기 게임 |

## 공부하는 방법

1. 파일을 열어 주석을 읽으며 코드를 이해합니다.
2. 실행해서 결과를 직접 확인합니다.
   ```
   python3 lessons/01_print_and_variables.py
   ```
3. 숫자나 글자를 바꿔 보며 결과가 어떻게 달라지는지 실험합니다.
4. 각 파일 맨 아래의 **✏️ 연습문제**를 풀어 봅니다.
