# StealthProto — 빛 감지 스텔스 프로토타입

`docs/ue5-migration/10-splinter-cell-chaos-theory.md` 의 **2단계(빛 감지)** 를
구현한 UE5 C++ 프로젝트입니다. 스플린터셀류 스텔스의 핵심이자 UE5에 대응
기능이 없는 부분이라 가장 먼저 만들었습니다.

> **아직 컴파일 검증이 안 된 코드입니다.** 이 저장소를 만든 환경에는 UE5가
> 설치되어 있지 않아 빌드를 돌려보지 못했습니다. 첫 빌드에서 오류가 나면
> 그 메시지를 그대로 알려주시면 고치겠습니다.

## 들어 있는 것

| 클래스 | 역할 |
|---|---|
| `UStealthLightingSubsystem` | 레벨의 광원을 등록해 두고, 임의 지점의 밝기를 계산 |
| `UExposureComponent` | 소유 액터의 노출도(0~1)와 단계(Hidden/Dim/Lit) 산출 |

렌더링 결과를 읽지 않고 **광원을 직접 순회해 계산**합니다. 그래서 조명을 끄거나
파괴하면 즉시 반영되고, 나중에 멀티플레이로 확장해도 서버에서 그대로 돌아갑니다.
대신 Lumen 간접광은 계산에 잡히지 않습니다.

## 시작하기

1. `StealthProto.uproject` 우클릭 → **Switch Unreal Engine version** 으로 설치된
   UE5 버전 지정 (`EngineAssociation`을 비워 뒀습니다)
2. 우클릭 → **Generate Visual Studio project files**
3. 솔루션을 열고 **Development Editor** 구성으로 빌드
4. 에디터가 뜨면 빈 레벨을 만들고:
   - 바닥 하나, 벽 몇 개, **Point Light** 2~3개 배치
   - 서드퍼슨 캐릭터(또는 아무 Pawn) 배치
   - 캐릭터에 **Exposure** 컴포넌트 추가
   - 컴포넌트 디테일 패널에서 **Draw Debug** 체크
5. 플레이하면 캐릭터 위에 `Exposure 0.42 (Dim) / Lights 3` 같은 텍스트가 뜨고,
   기여 중인 광원까지 노란 선이 그려집니다

## 튜닝

**`Reference Brightness` 하나만 만지면 됩니다.** 가장 밝은 곳에 섰을 때 노출값이
1.0 근처가 되도록 맞추십시오. 그 다음 `Hidden Threshold`(기본 0.15)와
`Lit Threshold`(기본 0.45)로 "어디까지가 안전한 그림자인가"를 정합니다.

디버그 표시를 켠 채로 조명 사이를 걸어 다니며 값이 어떻게 움직이는지 보는 것이
가장 빠릅니다. 이 감각을 잡기 전에 AI를 붙이면 뭐가 잘못됐는지 알 수 없습니다.

```
[다음] 뒤에서 제압

```

`OnExposureStateChanged` 델리게이트가 AI 연결 지점입니다. 경비의 감지 로직에서
이 단계를 읽어 시야 판정에 반영하십시오.
