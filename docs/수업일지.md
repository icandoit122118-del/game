## 1일차 — 2026-09-16 ✅

### 배운 것
| | 개념 | 요약 |
|---|---|---|
| 1 | `print()` | 화면에 보여줘 |
| 2 | 문자열 vs 숫자 | 따옴표 있으면 글자 그대로, 없으면 계산 |
| 3 | `+` 의 두 얼굴 | 숫자면 더하기(`10+5`→`15`), 글자면 붙이기(`"10"+"5"`→`105`) |
| 4 | 변수 | 이름표 상자. `이름 = "홍길동"` 하면 `이름` 부를 때 홍길동이 나옴 |
| 5 | f-string | `f"안녕하세요 {이름}님"` ← **숙제로 남음** |

### 학생이 실제로 친 코드
```python
print(3+5)                        # 8
print("3+5")                      # 3+5
print("안녕하세요")                 # 안녕하세요
print(10+5)                       # 15
print("10"+"5")                   # 105
이름 = "홍길동"; print(이름)        # 홍길동
print("안녕하세요 " + 이름 + "님")   # 안녕하세요 홍길동님
이름 = "최동섭"                     # 스스로 바꿔서 실험함 👍
print("안녕하세요" + 이름 + "님")    # 안녕하세요최동섭님 (공백 차이 발견)
```

### 잘한 점
- `"10"+"5"` 결과를 **이유까지 설명**하며 맞힘 ("글자니까 합친다")
- 시키지 않았는데 변수 값을 스스로 바꿔서 실험함
- 따옴표 안 공백 하나로 결과가 달라지는 걸 직접 만들어냄

### 헷갈렸던 점
- 변수가 **내용으로 치환**된다는 걸 처음엔 놓침 (`"안녕하세요 " + 이름 + "님"` 을 `안녕하세요 님`으로 예측)
- → 직접 실행해 보고 해결됨. **다음 수업에 한 번 더 확인할 것**

### 미완료 숙제
```python
이름 = "최동섭"
print(f"안녕하세요 {이름}님")
```
→ f-string. `+` 없이 `{ }` 로 변수를 끼워넣는 방법.
