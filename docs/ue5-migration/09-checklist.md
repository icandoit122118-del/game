# 09. 단계별 체크리스트와 리스크

## 9.1 실행 체크리스트

### 0단계 — 현황 조사
- [ ] `.uc` 소스 존재 여부 확인 (없으면 일정 2~3배 재산정)
- [ ] 확장자별 파일 수·용량 집계
- [ ] UnrealScript 총 라인 수 집계
- [ ] 자산별 "재사용 / 재제작 / 폐기" 판정표 작성
- [ ] 자체 제작 자산과 엔진 기본 자산 분리 (재배포 권한 확인)
- [ ] 원본 게임 실행 및 UnrealEd 구동, 레퍼런스 영상·스크린샷 확보
- [ ] **이식 범위 확정: 원작 재현 / 리마스터 / 리부트 중 택1 후 문서화**

### 1단계 — 프로젝트 셋업
- [ ] UE5 버전 고정 및 팀 전원 통일
- [ ] C++ Blank 프로젝트 생성 (프로젝트명 최종 확정)
- [ ] 폴더 구조·네이밍 규칙 합의 및 문서화
- [ ] Git LFS 설정, `.gitignore` / `.gitattributes` 적용
- [ ] 빈 프로젝트가 컴파일·패키징되는지 확인 후 커밋

### 2단계 — 자산 추출
- [ ] umodel / UTPT 로 텍스처·메시·사운드 추출
- [ ] 배치 변환 스크립트 작성 (`tools/convert/`)
- [ ] **스케일 2배 보정** 규칙을 임포트 프리셋에 반영
- [ ] `Content/Legacy/` 격리 구역으로 임포트
- [ ] 임포트 설정 검수 (sRGB, 압축, 콜리전, 스켈레톤)

### 3단계 — 수직 슬라이스 (최우선)
- [ ] GameMode / GameState / PlayerState 골격
- [ ] Character + 이동 (원본 감각 대비 튜닝)
- [ ] 무기 1종 (발사 → 히트 → 데미지 → 사망)
- [ ] 적 1종 (AIController + Behavior Tree)
- [ ] 간단한 HUD (UMG)
- [ ] **데디케이티드 서버 + 클라이언트 2명으로 위 루프 전체 동작 확인**
- [ ] 여기서 확립한 패턴을 팀 내부 가이드로 문서화

### 4단계 — 스크립트 이식
- [ ] 클래스별 이식 대상 표 작성 (C++ / BP / 데이터 에셋 / 폐기)
- [ ] 유틸리티 → 프레임워크 → Pawn → 무기 → AI → UI 순서로 진행
- [ ] 모든 오브젝트 포인터에 `UPROPERTY()` 부착 확인
- [ ] `simulated` 아니었던 함수에 권한 가드 추가 확인
- [ ] `Replicated` 프로퍼티와 `GetLifetimeReplicatedProps` 짝 검증

### 5단계 — 레벨 재구축
- [ ] 원본 맵 `.t3d` 추출 및 파서 작성
- [ ] 액터 배치 좌표 이관 (위치 ×2, 회전 ×360/65536)
- [ ] 참조 지오메트리 임포트 → 블록아웃 → 모듈러 메시 교체
- [ ] NavMesh 생성 및 AI 이동 검증
- [ ] 라이팅 (기준 씬 노출 고정 후 작업)
- [ ] 아이템/스폰 배치 밸런스 검증

### 6단계 — 멀티플레이
- [ ] 커스텀 이동의 클라이언트 예측 구현
- [ ] `Net PktLag` / `PktLoss` 환경 테스트
- [ ] 데디케이티드 서버 빌드 테스트
- [ ] `stat net` 대역폭 점검

### 7단계 — 최적화·출시
- [ ] Nanite / Lumen 적용 범위 결정 및 프로파일링
- [ ] `stat unit`, `stat gpu`로 프레임 예산 확인
- [ ] 패키징 및 대상 플랫폼 검증
- [ ] `Content/Legacy/` 잔여 자산 정리 (미사용 자산 제거)

## 9.2 주요 리스크

| 리스크 | 영향 | 완화 방법 |
|---|---|---|
| **`.uc` 소스 부재** | 이식 비용 2~3배 | 초기 조사에서 즉시 확인. 디컴파일 결과로 일정 재산정 |
| **스케일 보정 누락** | 후반 전면 재작업 | 프로젝트 시작 시점에 규칙 고정, 임포트 프리셋에 강제 |
| **범위 확대(scope creep)** | 일정 무한 연장 | "리마스터인가 리부트인가"를 문서로 고정. 변경 시 재승인 절차 |
| **레벨 재구축 비용 과소평가** | 일정의 대부분을 잠식 | 맵 1개를 끝까지 완성해 실측한 뒤 나머지 일정 산정 |
| **엔진 버전 혼용** | `.uasset` 손상 | 버전 고정, CI에서 검증 |
| **`UPROPERTY()` 누락 크래시** | 재현 어려운 간헐적 크래시 | 코드 리뷰 필수 항목. UnrealScript는 자동 GC 추적이었음을 팀에 주지 |
| **원본 자산 권리 문제** | 배포 불가 | 0단계에서 자체 제작 자산 분리, 엔진 기본 자산 의존 제거 |
| **PBR 미대응 텍스처** | 룩이 평평하거나 이중 음영 | de-lighting 또는 텍스처 재제작을 범위에 미리 포함 |
| **이동 감각 재현 실패** | 원작 팬층 이탈 | 3단계에서 최우선 검증. 후반 튜닝은 비용이 몇 배 |
| **UI 전면 재제작 누락** | 막판 병목 | Canvas 코드는 이식 불가임을 초기에 명시하고 UMG 일정 확보 |

## 9.3 성공 판정 기준

각 단계의 완료를 주관적 판단이 아니라 관찰 가능한 상태로 정의하십시오.

| 단계 | 완료 기준 |
|---|---|
| 0 | 판정표와 범위 문서가 팀 승인됨 |
| 1 | 빈 프로젝트가 CI에서 컴파일·패키징 성공 |
| 2 | 대표 자산 10종이 UE5에서 올바른 스케일·머티리얼로 표시됨 |
| 3 | 데디케이티드 서버에서 2인 플레이로 킬 루프가 완결됨 |
| 4 | 원본 클래스 목록의 이식 판정이 100% 결정되고 핵심 경로가 동작 |
| 5 | 맵 1개가 원본 레이아웃 대비 치수 오차 허용 범위 내에서 플레이 가능 |
| 6 | 100ms 지연·5% 손실 환경에서 플레이 가능 |
| 7 | 목표 플랫폼에서 목표 프레임레이트 달성 |
