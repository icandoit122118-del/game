## 0. 돈 안 쓰고 하는 법

### 사지 않아도 되는 것
| 흔히 사는 것 | 대신 |
|---|---|
| 파이썬 입문서 (2~3만원) | 점프 투 파이썬 (wikidocs, 무료 전문 공개) |
| 온라인 강의 (10~50만원) | 유튜브 무료 강의 + 이 커리큘럼 |
| 노트북/GPU (100만원+) | Google Colab 무료 (GPU 포함) |
| 수학 강의 | 칸아카데미 한국어 (무료) |
| ChatGPT Plus 등 구독 | 무료 티어 + 로컬 모델 |

### 실습 환경 (전부 무료)
- **Google Colab** — 브라우저에서 파이썬 실행. 무료 GPU도 제한적으로 줍니다. **1~15주는 이것만으로 충분.**
- **Kaggle Notebooks** — 매주 무료 GPU 시간을 줍니다. Colab보다 넉넉할 때가 있어 16주차 이후 예비용.
- **본인 컴퓨터** — 3주차 이후 로컬 파이썬. 사양 상관없습니다(모델을 직접 돌리는 게 아니라면).

### LLM을 무료로 쓰는 3가지 방법
1. **웹 채팅 무료 티어** — 프롬프트 연습(1·2학기)은 이것만으로 충분합니다. API 필요 없음.
2. **API 무료 크레딧 / 무료 티어** — 여러 제공사가 신규 가입 크레딧이나 무료 호출 한도를 줍니다.
   조건이 자주 바뀌니 **가입 시점에 직접 확인**하세요. 3학기 실습은 하루 수십 번 호출이면 되므로
   대개 무료 한도 안에서 끝납니다.
3. **로컬 모델 (완전 무료, 무제한)** — `Ollama`를 설치하면 오픈 가중치 모델을 내 컴퓨터에서 돌립니다.
   성능은 상용 모델보다 낮지만 **RAG·에이전트 구조를 연습하기엔 충분**합니다. 인터넷도 필요 없습니다.

> **비용이 걱정되면 3학기까지는 무료 티어로 버티고, 4학기 졸업작품에서만 소액(몇천 원) 쓰는 방식**을 권합니다.

### 수학에 대한 솔직한 이야기
- **1~7주: 수학 0.** 사칙연산이면 됩니다.
- **8~15주: 고등학교 수준 + 직관.** 행렬곱이 뭘 하는지, 확률분포가 뭔지 "그림으로" 알면 됩니다.
- **대학원 수준 수학이 필요한 사람**: 새 모델 구조를 **연구**하는 사람뿐입니다. AI로 **만드는** 사람은 아닙니다.

> **순서가 핵심입니다.** 수학을 먼저 다 하고 오려 하면 못 옵니다.
> 코드로 먼저 만져보고 → "이게 왜 되지?" 궁금할 때 그 수학만 찾아보세요. 흡수율이 다릅니다.

## 2. 24주 커리큘럼

하루 1시간, 주 5일 기준. 느려도 됩니다. **건너뛰지만 마세요.**

### 1학기 (1~3주) — 파이썬
> 상세 내용: [파이썬 기초 가이드](./python-basics.md)

| 주 | 배울 것 | 실습과제 | 통과 기준 |
|---|---|---|---|
| 1 | print, 변수, f-string, 리스트, 딕셔너리, for/if, 함수 | ① 5글자 넘는 단어만 출력 ② 이름·나이 받아 문장 만드는 함수 ③ 구구단 ④ 점수 80 이상만 골라내기 | 30줄 스크립트를 검색 없이 작성 |
| 2 | 컴프리헨션, 문자열 메서드, 파일 입출력, JSON, try/except | ① 텍스트 파일 단어수 세기 ② 긴 글 500자씩 자르기 ③ JSON 저장·불러오기 ④ 특정 단어 든 문장만 추출 | 파일을 읽어 가공 후 저장하는 프로그램 완성 |
| 3 | pip, 가상환경, 환경변수, requests, 첫 API 호출 | ① 가상환경 만들고 라이브러리 설치 ② 공개 API에서 JSON 받아오기 ③ LLM API 한 번 호출 ④ 질문 5개 반복 호출 후 저장 | **1학기 시험** (아래) 통과 |

**1학기 시험**: 텍스트 파일을 읽어 문단별로 나누고, 100자 이상 문단만 골라
`{"번호":1, "글자수":320, "미리보기":"..."}` 형태로 `result.json`에 저장. 파일 없으면 에러 처리.

### 2학기 (4~7주) — 데이터와 LLM 사용자
> 이 학기는 **수학 0, API 비용 0**입니다. 웹 채팅만으로도 대부분 됩니다.

| 주 | 배울 것 | 실습과제 | 통과 기준 |
|---|---|---|---|
| 4 | 토큰·컨텍스트·temperature·시스템 프롬프트 개념 | ① 한국어/영어 같은 문장 토큰수 비교 ② temperature 0 vs 1로 5회씩 비교 ③ 시스템 프롬프트만 바꿔 3회 비교 | 네 개념을 남에게 설명 가능 |
| 5 | 프롬프트 기법 (구체화, few-shot, 출력형식 고정, 단계적 사고) | ① 나쁜 프롬프트 5개를 좋게 고치기 ② few-shot으로 분류기 만들기 ③ JSON 스키마 고정 출력 받기 | 같은 과제에서 답변 품질이 눈에 띄게 개선 |
| 6 | 판다스 맛보기 + CSV/표 데이터 | ① CSV 읽어 통계 내기 ② 표의 각 행을 LLM으로 분류 ③ 결과를 새 CSV로 저장 | 100행짜리 데이터를 자동 분류 |
| 7 | 나만의 자동화 도구 만들기 (1차 프로젝트) | **프로젝트**: 내 반복 업무 하나를 자동화 (회의록 정리 / 메일 초안 / 기사 요약 / 가계부 분류 등) | 실제로 내가 매주 쓰는 도구 완성 |

**2학기 시험**: 텍스트 파일 10개를 읽어 각각 `{제목, 3문장요약, 키워드3개, 감정}`을
JSON으로 뽑아내는 프로그램. 실패한 파일은 건너뛰고 로그를 남길 것.

### 3학기 (8~15주) — 원리 (여기가 산)
> 수학이 등장합니다. **직관 수준까지만** 합니다. 못 풀어도 됩니다, 이해만 하면 됩니다.

| 주 | 배울 것 | 실습과제 | 통과 기준 |
|---|---|---|---|
| 8 | 벡터와 행렬 (3Blue1Brown 선형대수 1~4편) | ① 넘파이로 벡터 더하기·내적 ② 행렬곱 손으로 2×2 한 번 ③ 코사인 유사도 직접 구현 | "행렬곱은 공간을 변형하는 것"을 설명 가능 |
| 9 | 확률·로그 직관 (칸아카데미) | ① 주사위 시뮬레이션 1만 회 ② 확률분포 그려보기 ③ 로그를 쓰면 왜 편한지 실험 | 확률분포와 기대값을 설명 가능 |
| 10 | 토크나이저 (BPE) | ① 토크나이저로 한/영/코드 토큰수 비교 ② BPE를 20줄로 직접 구현 ③ "strawberry의 r 개수" 실험 | 한국어가 왜 비싼지 설명 가능 |
| 11 | 임베딩과 벡터 유사도 | ① 문장 20개 임베딩 ② 유사도 행렬 출력 ③ "왕-남자+여자" 실험 ④ 가장 비슷한 문장 찾기 | 의미가 벡터로 표현된다는 걸 실증 |
| 12 | 신경망 기초 + 미분·손실함수 직관 | ① 2차함수 기울기 손으로 구하기 ② 경사하강법 10줄 구현 ③ 크로스엔트로피 계산해보기 | "학습 = 오차 줄이는 방향으로 조금씩 이동"을 설명 |
| 13 | 어텐션과 Transformer | ① 어텐션 가중치 직접 계산(3토큰) ② 시각화 도구로 문장 어텐션 보기 ③ Q·K·V를 비유로 설명 써보기 | "그것은"이 뭘 가리키는지 모델이 어떻게 아는지 설명 |
| 14~15 | **작은 GPT 직접 만들기** (Karpathy "Let's build GPT") | **프로젝트**: 좋아하는 텍스트(가사·소설·대본)로 문자 단위 GPT 학습시켜 문장 생성 | 내 손으로 학습시킨 모델이 문장을 뱉음 |

**3학기 시험**: 다음을 각각 3문장으로 설명하시오 — ① 환각은 왜 생기는가
② temperature를 올리면 내부에서 무슨 일이 일어나는가 ③ 컨텍스트 윈도우 제한은 왜 존재하는가
④ 한국어가 영어보다 토큰을 많이 먹는 이유
